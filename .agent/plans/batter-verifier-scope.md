## Decision Log

Retain owned pool checkout, snapshot, identity restoration, deadline and retirement. Treat explicitly selected temporary namespaces, including pg_temp alias, other-session names and temporary routine argument identities, as unsupported; do not silently omit them or extend authorization simulation to session-specific namespaces. Apply the guard to combined, authority-only and migration-only requests before ledger locking. A two-connection PostgreSQL18.6 experiment established that native has_schema_privilege observes a concurrent grant while a repeatable-read nspacl query retains the earlier state (before t|f, after t|t). Native inquiry therefore cannot replace captured required evaluation without violating the single-snapshot contract. Retain the bounded captured-data model and conservative unknown/custom parameter handling; use native checks as differential test references on stable fixtures, with a regression preserving snapshot behavior during concurrent grants. Potential login authority remains a bounded, explicitly documented PostgreSQL18 subset.

An explicit PUBLIC relation policy suppresses column defaults; explicitly named column allowances remain available, and permitted whole-table privileges still cover columns. One shared policy index decides whether defaults apply in both required-policy validation and expansion. This is a deliberate tightening of the ambiguous deny/default interaction and will be documented.
