## Acceptance and API limits

No failing or unexecuted T-12 test acceptance remains. The original plan's raw
connection store and separately implemented native commit-error type were
superseded by the owner-selected `batter-sqlx` dependency and protected
`PooledStore`. Successful atomic/read-only operations retire instead of reusing
sessions. Native owner seams for a precise COMMIT send point and separately
bounded snapshot acquisition remain unavailable; the conservative behavior above
is implemented, tested and disclosed. Presence/publication/prune, process gates,
CLI and loader registration remain outside T-12. This is an implementation
handoff, not a review or task-closure claim.

The initial migration did not exist at the assigned baseline. Its SHA-384 pin is
`012496b1a41f85d61d47df47505258cb25f4a27b789a557f16c6f50f63050558ef896ec21ed5a50364f526a44997cff2`.
Existing migrations were not edited. The baseline package's `src/lib.rs` had no
public items; comparison with `git show 85f2c0d0:crates/batter-flags-postgres/src/lib.rs`
shows an additive surface, so there is no public hard cut or deprecated shim.
`Cargo.lock` was regenerated by Cargo using already cached dependencies.
