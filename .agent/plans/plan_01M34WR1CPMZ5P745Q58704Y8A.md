## Decision Log

Use `PgSessionProfile::with_timeouts` with seven required arguments, including all four durations. Store the two transaction settings as one optional private pair: None means legacy undeclared/reset defaults, Some includes explicit zero. Reuse exact bounded milliseconds and one settings iterator for apply and verify. PostgreSQL's native unknown-parameter error rejects unsupported complete profiles before application work; no broad version framework is needed.

ADR-010: complete construction requires all four choices and rejects invalid precision/range before I/O. Library-owned setup and existing scope checks enforce ordering. Relative timeout sizes and zero are application policy; arbitrary SQL between checks and remote termination remain limits. The existing constructor is an explicitly weaker compatibility path. No fresh-agent usability evaluation is claimed.
