## Decision Log

Use additive opt-in APIs. Opaque CorrelationId wraps a generated UUID from Tower HTTP's native MakeRequestUuid, replaces request and response identity, and provides explicit string propagation. One operational wrapper composes existing observe_response inside identity; it is installed after full router assembly and does not add admission. HTTP completion events store the typed ID directly, independent of INFO spans. Infrastructure JSON explicitly opts into code/message/request_id and no-store; default Problem JSON is unchanged. ReadinessPolicy reads lifecycle plus HealthReader, returns an explicit reason, and selects severity independently of its empty-body 200/503 response. Native register_http accepts an already bound TcpListener and initialized Router, delegates lifecycle ownership and drain to Supervisor. No durable state or migration changes.
